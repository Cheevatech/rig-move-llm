# v0.6.1 — cc engine becomes the auto-default

The default-flip gate (map10 P4) passed on all three axes — catch on real tasks with a
hidden gold judge (false-accept 0), a repo outside the measured set (xarray, −28.7%),
and a second endpoint of a different model family (converged, gold-resolved) — with the
cc engine cheaper than solo on every resolved pair (down to −75%).

- Engine selection is now **auto**: `RIG_CC_BASE_URL` configured ⇒ cc engine;
  otherwise the built-in 3-tool loop. `RIG_WORKER_ENGINE=cc|loop` still forces either.
- A plain install (no cc base URL) behaves exactly as before — no new dependency.
- All money-safety rails unchanged: empty base refuses, dummy API key, closed web posture.
